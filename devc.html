1
Find the angle between the surfaces x² + y² + z² = 9 and z = x² + y² − 3 at (2, −1, 2).
▾
Key Formula: Angle between two surfaces = angle between their normal vectors (gradients).
cos θ = (∇φ₁ · ∇φ₂) / (|∇φ₁| × |∇φ₂|)
Step 1 — Define the two surface functions

φ₁ = x² + y² + z² − 9     (first surface)

φ₂ = x² + y² − z − 3     (rearranging z = x² + y² − 3)

Step 2 — Compute ∇φ₁ (Normal to first surface)
∇φ₁ = (∂φ₁/∂x)i + (∂φ₁/∂y)j + (∂φ₁/∂z)k = 2x i + 2y j + 2z k At point (2, −1, 2): n₁ = 2(2)i + 2(−1)j + 2(2)k = 4i − 2j + 4k
Step 3 — Compute ∇φ₂ (Normal to second surface)
∇φ₂ = (∂φ₂/∂x)i + (∂φ₂/∂y)j + (∂φ₂/∂z)k = 2x i + 2y j + (−1)k At point (2, −1, 2): n₂ = 2(2)i + 2(−1)j + (−1)k = 4i − 2j − k
Step 4 — Compute dot product and magnitudes
n₁ · n₂ = (4)(4) + (−2)(−2) + (4)(−1) = 16 + 4 − 4 = 16 |n₁| = √(4² + (−2)² + 4²) = √(16 + 4 + 16) = √36 = 6 |n₂| = √(4² + (−2)² + (−1)²) = √(16 + 4 + 1) = √21
Step 5 — Find the angle
cos θ = (n₁ · n₂) / (|n₁| × |n₂|) = 16 / (6 × √21) = 16 / (6√21) = 8 / (3√21)
✅
θ = cos⁻¹(8 / 3√21) ≈ 54.41°
2
Find the angle between the surfaces xy = z² at (4, 1, 2) and (3, 3, −3).
▾
📌 Note: This is ONE surface φ = xy − z² = 0 with two different points. Find the angle between the normals at these two points.
Step 1 — Define the surface and compute ∇φ
φ = xy − z² ∇φ = (∂φ/∂x)i + (∂φ/∂y)j + (∂φ/∂z)k = y i + x j − 2z k
Step 2 — Normal at point A = (4, 1, 2)
n₁ = y i + x j − 2z k at (4,1,2) = (1)i + (4)j − 2(2)k = i + 4j − 4k |n₁| = √(1² + 4² + (−4)²) = √(1 + 16 + 16) = √33
Step 3 — Normal at point B = (3, 3, −3)
n₂ = y i + x j − 2z k at (3,3,−3) = (3)i + (3)j − 2(−3)k = 3i + 3j + 6k |n₂| = √(3² + 3² + 6²) = √(9 + 9 + 36) = √54 = 3√6
Step 4 — Dot product and angle
n₁ · n₂ = (1)(3) + (4)(3) + (−4)(6) = 3 + 12 − 24 = −9 cos θ = −9 / (√33 × 3√6) = −9 / (3√198) = −3 / √198 = −3 / (3√22) = −1 / √22
✅
θ = cos⁻¹(−1/√22) ≈ 102.3°    (Acute angle ≈ 77.7°)
3
Find values of a and b such that ax² − byz = (a+2)x and 4x²y + z³ = 4 cut orthogonally at (1, −1, 2).
▾
Key Concept: Two surfaces are orthogonal ⟺ their normal vectors are perpendicular ⟺ n₁ · n₂ = 0
Step 1 — Write surface functions
φ₁ = ax² − byz − (a+2)x φ₂ = 4x²y + z³ − 4
Step 2 — Compute ∇φ₁ at (1, −1, 2)
∂φ₁/∂x = 2ax − (a+2) → at x=1: 2a − (a+2) = a − 2 ∂φ₁/∂y = −bz → at z=2: −2b ∂φ₁/∂z = −by → at y=−1: b ∴ n₁ = (a−2)i − 2b j + b k
Step 3 — Compute ∇φ₂ at (1, −1, 2)
∂φ₂/∂x = 8xy → 8(1)(−1) = −8 ∂φ₂/∂y = 4x² → 4(1) = 4 ∂φ₂/∂z = 3z² → 3(4) = 12 ∴ n₂ = −8i + 4j + 12k
Step 4 — Condition 1: Point (1,−1,2) lies on φ₁ = 0
φ₁(1,−1,2) = 0 a(1)² − b(−1)(2) − (a+2)(1) = 0 a + 2b − a − 2 = 0 2b = 2 ∴ b = 1
Step 5 — Condition 2: Orthogonality n₁ · n₂ = 0
(a−2)(−8) + (−2b)(4) + (b)(12) = 0 −8a + 16 − 8b + 12b = 0 −8a + 16 + 4b = 0 Substituting b = 1: −8a + 16 + 4 = 0 −8a = −20 ∴ a = 5/2
✅
a = 5/2 ,   b = 1

Find the directional derivative of f(x,y,z) = xy³ + yz³ at (2,−1,1) in the direction of i + 2j + 2k.
▾
Key Formula: Directional Derivative = ∇f · â   where â = a⃗/|a⃗| is the unit vector in the given direction.
Step 1 — Compute gradient ∇f (general)
f = xy³ + yz³ ∂f/∂x = y³ ∂f/∂y = 3xy² + z³ ∂f/∂z = 3yz² ∴ ∇f = y³ i + (3xy² + z³) j + 3yz² k
Step 2 — Evaluate ∇f at (2, −1, 1)
∂f/∂x = (−1)³ = −1 ∂f/∂y = 3(2)(−1)² + (1)³ = 6 + 1 = 7 ∂f/∂z = 3(−1)(1)² = −3 ∴ ∇f at (2,−1,1) = −i + 7j − 3k
Step 3 — Find unit vector â
a⃗ = i + 2j + 2k |a⃗| = √(1² + 2² + 2²) = √(1 + 4 + 4) = √9 = 3 â = (1/3)i + (2/3)j + (2/3)k
Step 4 — Compute Directional Derivative
D.D. = ∇f · â = (−1)(1/3) + (7)(2/3) + (−3)(2/3) = −1/3 + 14/3 − 6/3 = (−1 + 14 − 6) / 3 = 7/3
✅
Directional Derivative = 7/3

Find D.D. of φ(x,y,z) = xy² + yz³ at (2,−1,1) in direction of normal to surface x log z − y² = −4 at (−1, 2, 1).
▾
Step 1 — Compute ∇φ at point (2, −1, 1)
φ = xy² + yz³ ∂φ/∂x = y² → (−1)² = 1 ∂φ/∂y = 2xy + z³ → 2(2)(−1) + 1 = −4 + 1 = −3 ∂φ/∂z = 3yz² → 3(−1)(1) = −3 ∴ ∇φ at (2,−1,1) = i − 3j − 3k
Step 2 — Find normal to surface ψ = x log z − y² + 4 = 0 at (−1, 2, 1)
∂ψ/∂x = log z → log(1) = 0 ∂ψ/∂y = −2y → −2(2) = −4 ∂ψ/∂z = x/z → (−1)/1 = −1 ∇ψ at (−1,2,1) = 0i − 4j − k |∇ψ| = √(0² + (−4)² + (−1)²) = √(0 + 16 + 1) = √17 Unit normal n̂ = (−4j − k) / √17
Step 3 — Compute Directional Derivative
D.D. = ∇φ · n̂ = (i − 3j − 3k) · (0i − 4j − k) / √17 = [(1)(0) + (−3)(−4) + (−3)(−1)] / √17 = [0 + 12 + 3] / √17 = 15 / √17
✅
Directional Derivative = 15/√17

Find D.D. of f = x² − y² + 2z² at P(1,2,3) in direction of PQ where Q=(5,0,4). Also find maximum D.D.
▾
Step 1 — Compute ∇f at P(1, 2, 3)
f = x² − y² + 2z² ∂f/∂x = 2x = 2(1) = 2 ∂f/∂y = −2y = −2(2) = −4 ∂f/∂z = 4z = 4(3) = 12 ∴ ∇f at P(1,2,3) = 2i − 4j + 12k
Step 2 — Find direction vector PQ⃗
PQ⃗ = Q − P = (5−1)i + (0−2)j + (4−3)k = 4i − 2j + k |PQ| = √(4² + (−2)² + 1²) = √(16 + 4 + 1) = √21 Unit vector â = (4i − 2j + k) / √21
Step 3 — Compute D.D. in direction PQ
D.D. = ∇f · â = [(2)(4) + (−4)(−2) + (12)(1)] / √21 = [8 + 8 + 12] / √21 = 28 / √21 = 28√21 / 21 = 4√21 / 3 (rationalised)
Step 4 — Maximum Directional Derivative = |∇f|
Maximum D.D. = |∇f| = √(2² + (−4)² + 12²) = √(4 + 16 + 144) = √164 = 2√41
✅
D.D. along PQ = 28/√21 = 4√21/3     Maximum D.D. = 2√41

Find D.D. of f = xy² + yz² + zx² along tangent to curve x=t, y=t², z=t³ at point (1,1,1).
▾
Step 1 — Compute ∇f at (1, 1, 1)
f = xy² + yz² + zx² ∂f/∂x = y² + 2zx → 1 + 2(1)(1) = 3 ∂f/∂y = 2xy + z² → 2(1)(1) + 1 = 3 ∂f/∂z = 2yz + x² → 2(1)(1) + 1 = 3 ∴ ∇f at (1,1,1) = 3i + 3j + 3k

r⃗(t) = t i + t² j + t³ k Tangent vector T⃗ = dr⃗/dt = i + 2t j + 3t² k At point (1,1,1): t = 1 [since x=t=1, y=t²=1, z=t³=1] T⃗ = i + 2(1)j + 3(1)²k = i + 2j + 3k |T⃗| = √(1² + 2² + 3²) = √(1 + 4 + 9) = √14 Unit tangent T̂ = (i + 2j + 3k) / √14
Step 3 — Compute D.D. along tangent
D.D. = ∇f · T̂ = [(3)(1) + (3)(2) + (3)(3)] / √14 = [3 + 6 + 9] / √14 = 18 / √14 = 18√14 / 14 = 9√14 / 7 (rationalised)
✅
D.D. along tangent = 18/√14

▾
Concept: Temperature increases fastest in the direction of the gradient ∇T. The maximum rate of change = |∇T|.

T = x² + y² − z ∂T/∂x = 2x ∂T/∂y = 2y ∂T/∂z = −1 ∴ ∇T = 2x i + 2y j − k

11
Prove div(rⁿr⃗) = (n+3)rⁿ, hence show that r⃗/r³ is solenoidal.
▾
Given: r⃗ = xi + yj + zk,   r = |r⃗| = √(x²+y²+z²)
Standard results: div r⃗ = 3    ∇(rⁿ) = nrⁿ⁻²r⃗
Step 1 — Apply product rule for divergence
div(rⁿ r⃗) = rⁿ(div r⃗) + r⃗ · ∇(rⁿ)
Step 2 — Compute each part
Part 1: div r⃗ = ∂x/∂x + ∂y/∂y + ∂z/∂z = 1 + 1 + 1 = 3 Part 2: ∇(rⁿ) = n·rⁿ⁻¹·∇r = n·rⁿ⁻¹·(r⃗/r) = n·rⁿ⁻²·r⃗ r⃗ · ∇(rⁿ) = r⃗ · (n·rⁿ⁻²·r⃗) = n·rⁿ⁻²·(r⃗·r⃗) = n·rⁿ⁻²·r² [since r⃗·r⃗ = r²] = n·rⁿ
Step 3 — Combine and conclude
div(rⁿ r⃗) = rⁿ · 3 + n·rⁿ = 3rⁿ + nrⁿ = (n + 3)rⁿ ∎ Proved.
Step 4 — Show r⃗/r³ is solenoidal
r⃗/r³ = r⁻³·r⃗ → this is of the form rⁿ·r⃗ with n = −3 Using the proved result: div(r⁻³·r⃗) = (−3 + 3)·r⁻³ = 0·r⁻³ = 0 Since div(r⃗/r³) = 0, the field r⃗/r³ is solenoidal. ∎
✅
div(rⁿr⃗) = (n+3)rⁿ Proved.    r⃗/r³ is solenoidal since div = 0 when n = −3.

Show F̄ = 2xyz²i + (x²z² + z cos yz)j + (2x²yz + y cos yz)k is irrotational and find the potential function.
▾
Step 1 — Identify P, Q, R
P = 2xyz² Q = x²z² + z cos yz R = 2x²yz + y cos yz
Step 2 — Check curl F̄ = 0 (compute all three components)
i-component = ∂R/∂y − ∂Q/∂z ∂R/∂y = 2x²z + cos yz − yz sin yz ∂Q/∂z = 2x²z + cos yz − yz sin yz i-comp = 0 ✓ j-component = −(∂R/∂x − ∂P/∂z) ∂R/∂x = 4xyz ∂P/∂z = 4xyz j-comp = 0 ✓ k-component = ∂Q/∂x − ∂P/∂y ∂Q/∂x = 2xz² ∂P/∂y = 2xz² k-comp = 0 ✓ ∴ curl F̄ = 0 → F̄ is irrotational. ∎
Step 3 — Find scalar potential φ from ∂φ/∂x = P
∂φ/∂x = 2xyz² Integrating w.r.t. x: φ = x²yz² + f(y, z) ... (i)
Step 4 — Use ∂φ/∂y = Q to find f(y,z)
∂φ/∂y = x²z² + ∂f/∂y = Q = x²z² + z cos yz ⟹ ∂f/∂y = z cos yz Integrating w.r.t. y: f(y, z) = sin yz + g(z) ... (ii)
Step 5 — Use ∂φ/∂z = R to find g(z)
φ = x²yz² + sin yz + g(z) ∂φ/∂z = 2x²yz + y cos yz + g'(z) = R = 2x²yz + y cos yz ⟹ g'(z) = 0 ⟹ g(z) = C (constant)
✅
F̄ is irrotational.    Scalar potential φ = x²yz² + sin(yz) + C

15
Prove: (i) div(curl f̄) = 0    (ii) curl(grad φ) = 0⃗
▾
Proof of (i): div(curl f̄) = 0
Let f̄ = P i + Q j + R k curl f̄ = (Ry − Qz)i + (Pz − Rx)j + (Qx − Py)k [where subscripts denote partial derivatives] div(curl f̄) = ∂/∂x(Ry − Qz) + ∂/∂y(Pz − Rx) + ∂/∂z(Qx − Py) = Ryx − Qzx + Pzy − Rxy + Qxz − Pyz = (Ryx − Rxy) + (Qxz − Qzx) + (Pzy − Pyz) = 0 + 0 + 0 [by equality of mixed partial derivatives: fxy = fyx] ∴ div(curl f̄) = 0 ∎
Proof of (ii): curl(grad φ) = 0⃗
grad φ = φx i + φy j + φz k curl(grad φ): i-component: ∂(φz)/∂y − ∂(φy)/∂z = φzy − φyz = 0 [by mixed partials] j-component: ∂(φx)/∂z − ∂(φz)/∂x = φxz − φzx = 0 k-component: ∂(φy)/∂x − ∂(φx)/∂y = φyx − φxy = 0 ∴ curl(grad φ) = 0⃗ ∎
✅
Both identities proved using equality of mixed partial derivatives (fxy = fyx).

17
Show that ∇²[f(r)] = f″(r) + (2/r)f′(r), where r = |r⃗|.
▾
Step 1 — Compute ∇[f(r)]
∇[f(r)] = f′(r)·∇r = f′(r)·(r⃗/r)
Step 2 — Apply divergence (product rule)
∇²f(r) = div[f′(r)/r · r⃗] = (f′(r)/r)·div(r⃗) + r⃗·∇(f′(r)/r) Part 1: div(r⃗) = 3 Part 2: ∇(f′(r)/r) = ∇[f′(r)]/r + f′(r)·∇(1/r) ∇[f′(r)] = f″(r)·(r⃗/r) ∇(1/r) = −r⃗/r³ ∴ ∇(f′(r)/r) = f″(r)·r⃗/r² − f′(r)·r⃗/r³ = r⃗[f″(r)/r² − f′(r)/r³]
Step 3 — Compute r⃗ · ∇(f′(r)/r)
r⃗ · ∇(f′(r)/r) = r⃗ · r⃗[f″(r)/r² − f′(r)/r³] = r² · [f″(r)/r² − f′(r)/r³] = f″(r) − f′(r)/r
Step 4 — Combine both parts
∇²f(r) = (f′(r)/r)·3 + f″(r) − f′(r)/r = 3f′(r)/r + f″(r) − f′(r)/r = f″(r) + 2f′(r)/r ∎
✅
∇²[f(r)] = f″(r) + (2/r)f′(r) Proved.

1
F̄ = 3xy i − y²j. Evaluate ∫_C F̄·dr̄ where C is y = 2x² from (0,0) to (1,2).
▾
Step 1 — Write the line integral

State: (i) Green's Theorem   (ii) Stokes' Theorem   (iii) Gauss Divergence Theorem
▾
(i) Green's Theorem
If P(x,y) and Q(x,y) have continuous partial derivatives in a closed region R bounded by a simple closed curve C, then: ∮_C (P dx + Q dy) = ∬_R (∂Q/∂x − ∂P/∂y) dA This converts a LINE INTEGRAL around a closed curve to a DOUBLE INTEGRAL over the enclosed region.
(ii) Stokes' Theorem
If F̄ has continuous first-order partial derivatives over an open surface S bounded by a closed curve C, then: ∮_C F̄·dr̄ = ∬_S (∇ × F̄)·n̂ dS = ∬_S curl F̄·n̂ dS This converts a LINE INTEGRAL around a closed curve C to a SURFACE INTEGRAL of the curl over surface S.
(iii) Gauss Divergence Theorem
If F̄ has continuous first-order partial derivatives in a closed volume V bounded by a closed surface S, then: ∯_S F̄·n̂ dS = ∭_V (∇·F̄) dV = ∭_V div F̄ dV This converts a SURFACE INTEGRAL (flux) over a closed surface to a VOLUME INTEGRAL of the divergence over the enclosed volume.
✅
Memory aid — Green's: 2D (curve→area) | Stokes': 3D curl (curve→surface) | Gauss: 3D div (surface→volume)
