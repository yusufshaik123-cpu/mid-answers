With neat diagrams, explain the following operations in Singly Linked List: a) Insert at beginning b) Insert at end c) Delete specified element d) Search given element
▾
Singly Linked List: A linear data structure where each node contains data and a next pointer to the next node. The last node points to NULL.
Node Structure
struct Node {
    int data;
    struct Node* next;
};
Diagram: [data | next] → [data | next] → [data | NULL]
          HEAD                                 TAIL
a) Insert at Beginning

Algorithm:

1. Create a new node with given data.
2. Set newNode→next = HEAD.
3. Update HEAD = newNode.

Before: HEAD → [10|→] → [20|→] → [30|NULL]

newNode = [5|→]

After:  HEAD → [5|→] → [10|→] → [20|→] → [30|NULL]
void insertAtBeginning(int data) {
    Node* newNode = new Node();
    newNode->data = data;
    newNode->next = head;
    head = newNode;
}

Time Complexity: O(1)

b) Insert at End

Algorithm:

1. Create a new node with given data; set newNode→next = NULL.
2. If list is empty, set HEAD = newNode.
3. Otherwise, traverse to the last node (where next = NULL).
4. Set lastNode→next = newNode.

Before: HEAD → [10|→] → [20|→] → [30|NULL]

newNode = [40|NULL]

After:  HEAD → [10|→] → [20|→] → [30|→] → [40|NULL]
void insertAtEnd(int data) {
    Node* newNode = new Node();
    newNode->data = data;
    newNode->next = NULL;
    if (head == NULL) { head = newNode; return; }
    Node* temp = head;
    while (temp->next != NULL)
        temp = temp->next;
    temp->next = newNode;
}

Time Complexity: O(n)

c) Delete Specified Element

Algorithm:

1. If HEAD→data == key, set HEAD = HEAD→next, free old head.
2. Traverse; keep a prev pointer.
3. When current→data == key, set prev→next = current→next, free current.

Delete 20 from: HEAD → [10|→] → [20|→] → [30|NULL]

prev=[10], curr=[20]
prev->next = curr->next  →  [10|→] → [30|NULL]

After: HEAD → [10|→] → [30|NULL]
void deleteNode(int key) {
    Node* temp = head, *prev = NULL;
    if (temp != NULL && temp->data == key) {
        head = temp->next; delete temp; return;
    }
    while (temp != NULL && temp->data != key) {
        prev = temp; temp = temp->next;
    }
    if (temp == NULL) return; // not found
    prev->next = temp->next;
    delete temp;
}

Time Complexity: O(n)

d) Search Given Element

Algorithm:

1. Start at HEAD, maintain position counter.
2. At each node check if data == key.
3. If found, return position. Else move to next.
4. If end reached (NULL), return "Not Found".

Search 20 in: HEAD → [10|→] → [20|→] → [30|NULL]

pos=1: 10 ≠ 20 → next
pos=2: 20 == 20 → FOUND at position 2
bool search(int key) {
    Node* temp = head;
    int pos = 1;
    while (temp != NULL) {
        if (temp->data == key) {
            cout << "Found at position " << pos;
            return true;
        }
        temp = temp->next; pos++;
    }
    cout << "Not Found"; return false;
}

Time Complexity: O(n)

✅
All four SLL operations use a HEAD pointer and sequential traversal. Insert-beginning is O(1); rest are O(n).

Write the algorithm and explain operations on Doubly Linked List: i) Add at beginning ii) Delete at beginning iii) Add after an item iv) Delete from end
▾
Doubly Linked List (DLL): Each node has three fields: prev pointer | data | next pointer. Allows traversal in both directions.
Node Structure
struct Node {
    int data;
    Node* prev;
    Node* next;
};

Diagram: NULL ← [prev|10|next] ⇌ [prev|20|next] ⇌ [prev|30|next] → NULL
         HEAD                                              TAIL
i) Add at Beginning

1. Create newNode. Set newNode→prev = NULL, newNode→next = HEAD.
2. If HEAD ≠ NULL, set HEAD→prev = newNode.
3. HEAD = newNode.

Before: HEAD → [NULL|10|→] ⇌ [←|20|NULL]
Insert 5:
After:  HEAD → [NULL|5|→] ⇌ [←|10|→] ⇌ [←|20|NULL]
void addAtBeginning(int data) {
    Node* newNode = new Node();
    newNode->data = data;
    newNode->prev = NULL;
    newNode->next = head;
    if (head != NULL) head->prev = newNode;
    head = newNode;
}
ii) Delete at Beginning

1. If HEAD == NULL, list is empty; return.
2. Store HEAD in temp. HEAD = HEAD→next.
3. If new HEAD ≠ NULL, set HEAD→prev = NULL.
4. Delete temp.

Before: HEAD → [NULL|5|→] ⇌ [←|10|→] ⇌ [←|20|NULL]
After:  HEAD → [NULL|10|→] ⇌ [←|20|NULL]
void deleteAtBeginning() {
    if (head == NULL) return;
    Node* temp = head;
    head = head->next;
    if (head != NULL) head->prev = NULL;
    delete temp;
}
iii) Add After a Given Item

1. Traverse to find node with data == key.
2. Create newNode. Set newNode→prev = curr, newNode→next = curr→next.
3. If curr→next ≠ NULL, set curr→next→prev = newNode.
4. curr→next = newNode.

Insert 15 after 10:
Before: [10] ⇌ [20]
After:  [10] ⇌ [15] ⇌ [20]
void addAfter(int key, int data) {
    Node* curr = head;
    while (curr != NULL && curr->data != key)
        curr = curr->next;
    if (curr == NULL) return;
    Node* newNode = new Node();
    newNode->data = data;
    newNode->next = curr->next;
    newNode->prev = curr;
    if (curr->next != NULL) curr->next->prev = newNode;
    curr->next = newNode;
}
iv) Delete from End

1. If HEAD == NULL, return. If HEAD→next == NULL, delete HEAD, HEAD = NULL.
2. Traverse to the last node (where next == NULL).
3. Set second-last node's next = NULL. Delete last node.

Before: [10] ⇌ [20] ⇌ [30|NULL]
After:  [10] ⇌ [20|NULL]
void deleteFromEnd() {
    if (head == NULL) return;
    Node* temp = head;
    if (head->next == NULL) { delete head; head = NULL; return; }
    while (temp->next != NULL) temp = temp->next;
    temp->prev->next = NULL;
    delete temp;
}
✅
DLL maintains both prev and next pointers. All operations require careful update of both links to avoid broken chain.

▾
a) Reversing a Singly Linked List

Concept: We reverse the direction of all next pointers using three pointers: prev, curr, and next.

Algorithm:

1. Initialize: prev = NULL, curr = HEAD, next = NULL.
2. While curr ≠ NULL:
 a. next = curr→next      (save next node)
 b. curr→next = prev      (reverse the link)
 c. prev = curr             (move prev forward)
 d. curr = next             (move curr forward)
3. HEAD = prev.

Original: HEAD → [1] → [2] → [3] → [4] → NULL

Step 1: prev=NULL, curr=[1]
  next=[2], [1]→NULL, prev=[1], curr=[2]

Step 2: prev=[1], curr=[2]
  next=[3], [2]→[1], prev=[2], curr=[3]

Step 3: prev=[2], curr=[3]
  next=[4], [3]→[2], prev=[3], curr=[4]

Step 4: prev=[3], curr=[4]
  next=NULL, [4]→[3], prev=[4], curr=NULL

HEAD = prev = [4]
Reversed: HEAD → [4] → [3] → [2] → [1] → NULL
void reverse() {
    Node* prev = NULL, *curr = head, *next = NULL;
    while (curr != NULL) {
        next = curr->next;
        curr->next = prev;
        prev = curr;
        curr = next;
    }
    head = prev;
}

Time Complexity: O(n)    Space Complexity: O(1)

b) Applications of Linked List

1. Implementation of Stacks and Queues: Linked lists are used to implement dynamic stacks and queues where size is not fixed in advance. Push/pop and enqueue/dequeue map directly to insert/delete at ends.

2. Polynomial Representation: Each node stores a (coefficient, exponent) pair. Addition and multiplication of polynomials become node-level operations.

3x² + 5x + 6  →  [3|2|→] → [5|1|→] → [6|0|NULL]

3. Implementation of Graphs (Adjacency List): Each vertex has a linked list of its adjacent vertices. Efficient for sparse graphs.

4. Dynamic Memory Allocation: OS maintains a free-list of memory blocks as a linked list. malloc/free operations use this list.

5. Music/Image Playlist: Songs or images in a media player are stored as a doubly linked list to support next/previous navigation.

6. Undo/Redo Functionality: Text editors maintain a linked list of states to support undo/redo operations.

7. Hash Chaining: In hash tables, each bucket contains a linked list to handle collisions.

8. LRU Cache Implementation: Doubly linked list combined with a hash map implements Least Recently Used cache efficiently.

✅
Reversal uses three pointers in O(n) time O(1) space. Linked lists are fundamental to stacks, queues, graphs, OS memory management, and caching.

Circular Linked List (CLL): Similar to SLL but the last node's next pointer points back to HEAD instead of NULL. There is no NULL terminator.
Structure and Diagram
struct Node {
    int data;
    Node* next;
};

Diagram:
HEAD → [10|→] → [20|→] → [30|→] → [40|→]
         ↑___________________________________|
         (last node points back to HEAD)
Operation 1: Insert at Beginning

1. Create newNode.
2. If list empty: newNode→next = newNode; HEAD = newNode; return.
3. Traverse to last node (where last→next == HEAD).
4. newNode→next = HEAD; last→next = newNode; HEAD = newNode.

Before: HEAD→[10]→[20]→[30]→(back to HEAD)
Insert 5:
After:  HEAD→[5]→[10]→[20]→[30]→(back to HEAD)
Operation 2: Insert at End

1. Create newNode.
2. If empty: newNode→next = newNode; HEAD = newNode; return.
3. Traverse to last node (last→next == HEAD).
4. newNode→next = HEAD; last→next = newNode.

Before: HEAD→[10]→[20]→[30]→(back to HEAD)
Insert 40:
After:  HEAD→[10]→[20]→[30]→[40]→(back to HEAD)
Operation 3: Delete a Node

1. If empty, return.
2. If HEAD is the only node and HEAD→data == key: HEAD = NULL; return.
3. If HEAD→data == key: find last node; last→next = HEAD→next; HEAD = HEAD→next; delete old head; return.
4. Otherwise, traverse to find node with matching data and link prev→next = curr→next; delete curr.

Delete 20 from: HEAD→[10]→[20]→[30]→(back to HEAD)
prev=[10], curr=[20]
[10]->next = [30]
After: HEAD→[10]→[30]→(back to HEAD)
Operation 4: Traversal / Display

1. If HEAD == NULL, print "Empty".
2. Start at HEAD, print data.
3. Move to next; repeat until we reach HEAD again.

void display() {
    if (head == NULL) { cout << "Empty"; return; }
    Node* temp = head;
    do {
        cout << temp->data << " ";
        temp = temp->next;
    } while (temp != head);
}
Operation 5: Search

1. Start at HEAD. Use do-while to visit each node once.
2. Compare data with key. If match found, return true.
3. If we loop back to HEAD without finding, return false.

bool search(int key) {
    if (head == NULL) return false;
    Node* temp = head;
    do {
        if (temp->data == key) return true;
        temp = temp->next;
    } while (temp != head);
    return false;
}
Advantages of Circular Linked List

• Any node can be a starting point.
• Useful in round-robin scheduling (OS processes).
• Traversal never needs NULL checks.
• Efficient for circular queue implementation.

✅
CLL has no NULL — last node links back to HEAD. All operations use do-while loop to detect full traversal. Used in OS scheduling and circular buffers.

a) Stack Using Array
Stack: A linear data structure that follows LIFO (Last In First Out) principle. All insertions and deletions occur at one end called the TOP.

Array Representation:

#define MAX 100
int stack[MAX];
int top = -1;   // Empty stack indicator

Push Operation:

void push(int data) {
    if (top == MAX - 1) {
        cout << "Stack Overflow!"; return;
    }
    stack[++top] = data;
}

Trace: Push 10, 20, 30
top=-1 → push(10) → stack[0]=10, top=0
         push(20) → stack[1]=20, top=1
         push(30) → stack[2]=30, top=2

Stack: [10, 20, 30]
              ↑ TOP (index 2)

Pop Operation:

int pop() {
    if (top == -1) {
        cout << "Stack Underflow!"; return -1;
    }
    return stack[top--];
}

pop() → returns 30, top=1
pop() → returns 20, top=0

Peek / Top:

int peek() {
    if (top == -1) return -1;
    return stack[top];
}
isEmpty(): return (top == -1)
isFull():  return (top == MAX-1)

Time Complexity: Push = O(1), Pop = O(1), Peek = O(1)

b) Evaluation of Postfix Expression Using Stack
Postfix: Operators come AFTER their operands. No parentheses needed. Example: A B + C * means (A+B)*C.

Algorithm:

1. Scan the postfix expression left to right.
2. If operand → PUSH onto stack.
3. If operator → POP two operands (op2 first, op1 second), apply operator, PUSH result.
4. Final answer is the top of the stack.

Example: Evaluate   6 2 3 + - 3 8 2 / + *

Token   Action            Stack
6       Push 6            [6]
2       Push 2            [6, 2]
3       Push 3            [6, 2, 3]
+       pop 3,2 → 2+3=5   [6, 5]
-       pop 5,6 → 6-5=1   [1]
3       Push 3            [1, 3]
8       Push 8            [1, 3, 8]
2       Push 2            [1, 3, 8, 2]
/       pop 2,8 → 8/2=4   [1, 3, 4]
+       pop 4,3 → 3+4=7   [1, 7]
*       pop 7,1 → 1*7=7   [7]

Result = 7
✅
Stack array uses top=-1 for empty. Postfix evaluation scans left to right: push operands, pop two for each operator, push result.

a) Queue – Enqueue and Dequeue
Queue: A linear data structure that follows FIFO (First In First Out). Insertion (Enqueue) at REAR, Deletion (Dequeue) at FRONT.
#define MAX 5
int queue[MAX];
int front = -1, rear = -1;

Enqueue Algorithm:

void enqueue(int data) {
    if (rear == MAX - 1) { cout << "Queue Full"; return; }
    if (front == -1) front = 0;   // first insertion
    queue[++rear] = data;
}

Dequeue Algorithm:

int dequeue() {
    if (front == -1 || front > rear) {
        cout << "Queue Empty"; return -1;
    }
    int val = queue[front++];
    if (front > rear) front = rear = -1;  // reset if empty
    return val;
}

Trace Example:

Enqueue 10, 20, 30, 40:
front=0, rear=3
Queue: [10, 20, 30, 40]
        ↑front        ↑rear

Dequeue → returns 10, front=1
Queue: [_, 20, 30, 40]
           ↑front  ↑rear

Dequeue → returns 20, front=2
Queue: [_, _, 30, 40]
              ↑front ↑rear

Problem: Even if front has moved, the rear can't use those empty slots — wasted space. This is fixed by Circular Queue.

b) Circular Queue – Enqueue and Dequeue
Circular Queue: Uses modular arithmetic so that rear wraps around to the beginning when it reaches MAX-1. Solves the wasted space problem of linear queue.
#define MAX 5
int cq[MAX];
int front = -1, rear = -1;

Enqueue:

void enqueue(int data) {
    if ((rear + 1) % MAX == front) { cout << "Full"; return; }
    if (front == -1) { front = rear = 0; }
    else rear = (rear + 1) % MAX;
    cq[rear] = data;
}

Dequeue:

int dequeue() {
    if (front == -1) { cout << "Empty"; return -1; }
    int val = cq[front];
    if (front == rear) { front = rear = -1; }  // last element
    else front = (front + 1) % MAX;
    return val;
}

Circular Trace (MAX=5):

Enqueue 10,20,30,40: front=0, rear=3
Dequeue → 10: front=1
Dequeue → 20: front=2
Enqueue 50: rear=(3+1)%5=4  →  [_,_,30,40,50]
Enqueue 60: rear=(4+1)%5=0  →  [60,_,30,40,50]  ← wrap around!
front=2, rear=0 (wraps around)
✅
Linear queue wastes space after dequeue. Circular queue uses (index+1)%MAX to wrap rear around, utilizing all slots efficiently.

b) Two Types of Queues

Type 1: Double-Ended Queue (Deque)

Insertions and deletions are allowed at both ends (front and rear). Two variants: Input-restricted deque (insert only at rear) and Output-restricted deque (delete only at front).
Operations:
  insertFront(x)  – insert at front
  insertRear(x)   – insert at rear
  deleteFront()   – delete from front
  deleteRear()    – delete from rear

Example:
  Start:   [ ]
  insertRear(10)  → [10]
  insertRear(20)  → [10, 20]
  insertFront(5)  → [5, 10, 20]
  deleteRear()    → [5, 10]     (removes 20)
  deleteFront()   → [10]        (removes 5)

Application: Sliding window problems, palindrome checking.

Type 2: Priority Queue

Each element has a priority value. Element with the highest priority is dequeued first, regardless of insertion order.
Example (min-priority = highest priority):

Insert: (Task A, priority=3), (Task B, priority=1), (Task C, priority=2)

Internal order by priority:
Priority Queue: [(B,1), (C,2), (A,3)]

Dequeue → (B,1)  ← lowest number = highest priority
Dequeue → (C,2)
Dequeue → (A,3)

Implementation: Min-Heap or sorted array
Application: CPU scheduling, Dijkstra's algorithm, Huffman coding.
✅
Circular queue eliminates wasted space via modular arithmetic. Deque allows both-end operations; Priority queue serves highest-priority elements first.

Algorithm:

1. Initialize empty stack.
2. Scan expression left to right.
3. If operand → PUSH it.
4. If operator → POP op2, POP op1. Compute (op1 operator op2). PUSH result.
5. Final stack top = answer.

a) Binary Tree – Definition and Properties
Binary Tree: A hierarchical data structure in which each node has at most two children — referred to as the left child and the right child.
Node Structure:
struct Node {
    int data;
    Node* left;
    Node* right;
};

Example Binary Tree:
           1          ← Root (Level 0)
          / \
         2   3        ← Level 1
        / \   \
       4   5   6      ← Level 2 (Leaf nodes: 4,5,6)

Properties of Binary Tree:

1. Max nodes at level i: 2^i   (root is level 0)
Example: Level 2 can have at most 2² = 4 nodes.

2. Max total nodes in tree of height h: 2^(h+1) − 1
Example: Height 2 tree → max 2³−1 = 7 nodes.

3. Min height for n nodes: ⌊log₂n⌋

4. Number of leaf nodes = Number of internal nodes with 2 children + 1

5. A strictly binary tree has every node with 0 or 2 children (never 1).

6. A complete binary tree has all levels full except possibly the last, filled left to right.

7. A full/perfect binary tree has all leaf nodes at the same level; all internal nodes have exactly 2 children.

Types:
• Full Binary Tree: Every node has 0 or 2 children.
• Complete Binary Tree: All levels full; last level left-to-right filled.
• Perfect Binary Tree: All internal nodes have 2 children; all leaves at same level.
• Skewed Binary Tree: All nodes have only one child (left-skewed or right-skewed).

b) BST Insertion Operation
Binary Search Tree (BST): For every node N: all nodes in left subtree < N, and all nodes in right subtree > N.

Insertion Algorithm:

1. If root == NULL, new node becomes root.
2. If data < root→data → go to left subtree recursively.
3. If data > root→data → go to right subtree recursively.
4. Insert when NULL position found.

Node* insert(Node* root, int key) {
    if (root == NULL) {
        Node* newNode = new Node();
        newNode->data = key;
        newNode->left = newNode->right = NULL;
        return newNode;
    }
    if (key < root->data)
        root->left = insert(root->left, key);
    else if (key > root->data)
        root->right = insert(root->right, key);
    return root;
}

Example: Insert 50, 30, 70, 20, 40, 60, 80

Insert 50:        50
Insert 30:        50
                 /
                30
Insert 70:        50
                 /  \
                30   70
Insert 20:        50
                 /  \
                30   70
               /
              20
Insert 40:        50
                 /  \
                30   70
               /  \
              20   40
Insert 60,80:     50
                 /  \
                30   70
               /  \  / \
              20  40 60  80

Time Complexity: Average O(log n), Worst O(n) (skewed tree)

✅

a) Graph and Its Representations
Graph G = (V, E): A non-linear data structure consisting of a set of Vertices (V) (nodes) and a set of Edges (E) (connections between vertices).

Types: Directed (Digraph) / Undirected, Weighted / Unweighted, Connected / Disconnected.

Example Graph:

Vertices: {A, B, C, D, E}
Edges (undirected): {(A,B), (A,C), (B,D), (C,D), (D,E)}

     A
    / \
   B   C
    \ /
     D
     |
     E

Representation 1: Adjacency Matrix

A 2D array M of size V×V where:
M[i][j] = 1 if edge exists between vertex i and j
M[i][j] = 0 otherwise

     A  B  C  D  E
A  [ 0  1  1  0  0 ]
B  [ 1  0  0  1  0 ]
C  [ 1  0  0  1  0 ]
D  [ 0  1  1  0  1 ]
E  [ 0  0  0  1  0 ]

Space Complexity: O(V²)
Advantage: O(1) edge lookup
Disadvantage: Wastes space for sparse graphs

Representation 2: Adjacency List

Each vertex has a linked list of its neighbors.

A → [B] → [C] → NULL
B → [A] → [D] → NULL
C → [A] → [D] → NULL
D → [B] → [C] → [E] → NULL
E → [D] → NULL

Space Complexity: O(V + E)
Advantage: Efficient for sparse graphs
Disadvantage: O(V) for edge lookup (worst case)
b) BFS – Data Structure and Traversal
BFS uses a QUEUE (FIFO). It visits all vertices at the current depth before going to the next level — hence called "breadth-first".

BFS Algorithm:

void BFS(int start) {
    visited[start] = true;
    queue.enqueue(start);
    while (!queue.isEmpty()) {
        int v = queue.dequeue();
        print(v);
        for each neighbor u of v:
            if (!visited[u]) {
                visited[u] = true;
                queue.enqueue(u);
            }
    }
}

BFS Algorithm (Complete)
Algorithm BFS(Graph G, start vertex s):
1. Create visited[] array, initialize all to false
2. Create empty Queue Q
3. Mark visited[s] = true
4. Enqueue s into Q
5. While Q is not empty:
    a. v = Dequeue from Q
    b. Process / Print v
    c. For each neighbor u of v:
       i.  If visited[u] == false:
           - visited[u] = true
           - Enqueue u into Q
6. End

DFS Algorithm (Complete)
Algorithm DFS(Graph G, start vertex s):
1. Create visited[] array, initialize all to false
2. Call DFS_Visit(s)

DFS_Visit(v):
1. Mark visited[v] = true
2. Process / Print v
3. For each neighbor u of v:
    a. If visited[u] == false:
       - DFS_Visit(u)   ← Recursive call

Iterative DFS using STACK:

Algorithm DFS_Iterative(G, s):
1. Create visited[] array
2. Create Stack S
3. Push s onto S
4. While S is not empty:
    a. v = Pop from S
    b. If visited[v] == false:
       - visited[v] = true
       - Print v
       - For each neighbor u of v (in reverse order):
         Push u onto S
5. End

Comparison: BFS vs DFS
Feature         BFS                      DFS
Data Structure  Queue (FIFO)             Stack (LIFO) / Recursion
Traversal       Level by level           One path as deep as possible
Time            O(V + E)                 O(V + E)
Space           O(V)                     O(V) (recursion depth)
Use Case        Shortest path, web crawl Topological sort, cycle detection
Completeness    Complete                 May not find shortest path
✅
BFS (Queue) gives level-order: 0→1→2→3→4. DFS (Stack/Recursion) goes deep first: 0→1→3→4→2. Both have O(V+E) time complexity.
